# Contributing

**This is a personal fork — external PRs are not accepted.**

This repository is maintained for personal and family use. The MCP touches sensitive local data (Photos, Notes, Reminders, Mail, Messages, Calendar, Contacts), and the safest contribution policy for that threat model is to keep the merge surface to one person.

## If you have a fix or improvement to contribute

Please submit it to the upstream project: **[supermemoryai/apple-mcp](https://github.com/supermemoryai/apple-mcp)**. That's where community work belongs. Once it lands upstream, this fork can pull it in.

## If you found a security issue

Open an issue in the upstream repo if it affects them too. For something specific to this fork, contact the owner directly rather than filing a public report.

## If you want to use this code

The MIT license applies. Clone, fork, modify for your own use freely — but don't expect PRs to this repository to be reviewed or merged.

---

*The author reviews every line of code that runs locally on their family's machines. External PRs, no matter how well-intentioned, create review burden disproportionate to the value of accepting them. Forking is the right pattern here, not contributing.*
